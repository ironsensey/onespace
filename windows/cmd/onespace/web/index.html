Bluetooth device switching · research preview

Automatic switching is not implemented. Bluetooth accessory identities cannot replace host-specific pairing, and Android prevents ordinary apps from silently enabling Bluetooth on modern versions. A verified per-accessory handoff system is planned for later.

Publish an Android update

Select the release-signed APK built from OneSpace Android source. Only paired Android devices can download it over the encrypted local connection. Android will verify the APK checksum and its installed signing certificate.

The Android APK package name and version are read automatically. No manual version fields needed.

How app updates work

1. Build a new signed APK with the same signing key and higher versionCode.
2. Publish it here on your PC.
3. On Android open OneSpace Updates → Check for Android app updates.
4. Download and approve Android installation.

The Windows service needs to be online on the same private network. This is a user-initiated local updater, not a silent background installer. Keep your signing key safe.
