# Start here — v0.9.0 Independent Preview

Follow [SETUP-v0.9.0.md](SETUP-v0.9.0.md) in order. The earlier live-only notes
are archived under docs/previous-v0.7.0, and v0.8.0 notes under docs/previous-v0.8.0.
Google account consent and recording details remain in DRIVE-SETUP.md.

Keep Windows %AppData%\OneSpace, the Pi identity and your original Android
signing key. No existing installation has been changed by this cloud build.
Use the native Windows app normally; use -legacy-ui only for troubleshooting.
Closing the native dashboard now stops the PC engine. Minimize it to keep PC
sharing running. The Pi and phone-to-Pi features can work while Windows is off.
